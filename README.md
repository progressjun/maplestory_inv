# 🏰 판타지 RPG 감성 모바일 청첩장

서로 다른 길을 걷던 두 사람이 만나 새로운 모험을 시작하는 이야기의 **모바일 청첩장**입니다.
2000년대 감성의 귀여운 2D 횡스크롤 판타지 게임 분위기를 **100% 오리지널 그래픽**으로 구현했습니다.
(특정 게임의 로고·캐릭터·맵·폰트 등은 사용하지 않았습니다.)

> 러버블(Lovable) · Vercel 등에 그대로 올릴 수 있는 **Vite + React + TypeScript + Tailwind** 단일 페이지 앱입니다.

---

## ✨ 주요 특징

- **단일 페이지** — 스크롤을 내리면 아침 하늘 → 숲 → 구름 위 마을 → 시계탑 광장 → 노을 성으로 이어지는 하나의 게임 월드
- **모바일 퍼스트** — 390px 기준, 320px까지 지원, PC에서는 480px 카드가 중앙에 표시(뒤에 흐린 하늘 배경)
- **오프닝 연출** — 신랑·신부가 양쪽에서 걸어와 만나고 하트가 피어오르는 애니메이션 (인트로 영상으로 교체 가능)
- **D-day 자동 계산** — `D-100`, `D-DAY`, `D+1` 형태
- **직접 디자인한 달력**, 사진 갤러리(스와이프/키보드), 오시는 길(지도 앱 버튼), 계좌 아코디언, 연락처, 공유
- **접근성 & 안정성** — `prefers-reduced-motion` 대응, 키보드/ESC 조작, 이미지·영상·복사·공유 실패 시 안전한 폴백, 콘솔 오류 없음

## 📝 내용 수정 방법 (개발 몰라도 OK)

거의 모든 텍스트·이미지·연락처·계좌는 **딱 한 파일**에서 관리합니다.

```
src/config/wedding.ts
```

- `[대괄호]` 로 표시된 값은 "무엇을 넣어야 하는지" 알려주는 임시 안내문입니다. 실제 값으로 바꿔주세요.
- 값을 `""`(빈 문자열) 또는 `[]`(빈 배열)로 두면 해당 **버튼/섹션이 자동으로 숨겨집니다.**
- 예) 신랑 전화번호를 넣으면 프로필·연락처에 전화/문자 버튼이 나타납니다.

### 이미지 · 영상 넣기

1. 사진/영상 파일을 `public/assets/` 폴더에 넣습니다.
2. `wedding.ts` 에서 경로를 `/assets/파일명` 형태로 지정합니다.

| 항목 | 설정 값 | 예시 |
|------|---------|------|
| 인트로 영상 | `introVideo` | `/assets/intro.mp4` |
| 대표 사진 | `heroImage` | `/assets/hero.jpg` |
| 갤러리 | `gallery` | `["/assets/gallery/01.webp", ...]` (최대 20장) |
| 신랑/신부 캐릭터 | `groom.image` / `bride.image` | 배경이 투명한 PNG 권장 |
| 웨딩 영상 | `weddingVideoUrl` | 유튜브/비메오 링크 또는 mp4 주소 |

> 이미지·영상이 없어도 예쁜 일러스트 플레이스홀더가 표시되어 디자인이 유지됩니다.

### 공유 미리보기(카카오톡/네이버) 이미지

- `public/assets/og-image.png` 파일을 넣고, `index.html` 과 `wedding.ts`의 `shareImage` 를 맞춰주세요. (권장 1200×630)
- `favicon` 은 `public/favicon.svg` 를 교체하면 됩니다.

## 🚀 실행 & 배포

```bash
npm install      # 의존성 설치
npm run dev      # 개발 서버 (http://localhost:8080)
npm run build    # 프로덕션 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

### Vercel 배포
1. 이 저장소를 Vercel에 연결합니다.
2. Framework Preset: **Vite** (자동 인식)
3. Build Command `npm run build`, Output Directory `dist` — 별도 설정 없이 그대로 배포됩니다.

### 러버블(Lovable)에서 열기
Vite + React + TypeScript + Tailwind 표준 구조라, GitHub 저장소를 그대로 연결해 이어서 편집할 수 있습니다.

## 🗂 폴더 구조

```
src/
├─ config/wedding.ts     ← ⭐ 여기만 고치면 됩니다 (모든 콘텐츠)
├─ App.tsx               ← 섹션 조립 + 월드 배경
├─ sections/             ← 12개 섹션 (오프닝~엔딩)
├─ components/           ← 캐릭터·풍경·파티클·토스트·UI
├─ hooks/                ← D-day/스크롤 등장/모션 감지
└─ lib/utils.ts          ← 복사·링크·영상 URL 등 유틸
```
