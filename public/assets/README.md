# /public/assets — 이미지 · 영상 넣는 곳

여기에 파일을 넣고 `src/config/wedding.ts` 에서 경로를 지정하세요.

권장 파일 목록 (있는 것만 넣으면 됩니다):

- `intro.mp4`        — 오프닝 인트로 영상
- `intro-poster.jpg` — 인트로 영상 표지 이미지
- `hero.jpg`         — 대표 사진 (4:5 권장)
- `groom.png`        — 신랑 캐릭터 (배경 투명 PNG)
- `bride.png`        — 신부 캐릭터 (배경 투명 PNG)
- `gallery/01.webp`, `gallery/02.webp` … — 갤러리 사진 (최대 20장, WebP/AVIF 권장)
- `og-image.png`     — 카카오톡/네이버 공유 미리보기 (1200×630)
- `bgm.mp3`          — 배경음악 (선택)

파일 경로 예시: `public/assets/hero.jpg` → 설정값 `"/assets/hero.jpg"`
